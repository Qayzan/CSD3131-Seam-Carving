How it works

01

Energy

Every pixel gets an energy, the change in brightness around it measured with a 3 × 3 Sobel filter: |Gx| + |Gy|. Edges score high, flat sky scores low.

02

Cheapest seam

A vertical seam takes one pixel per row, each touching the one above. Dynamic programming fills a table row by row with the cheapest way to reach every pixel, then follows it back up from the cheapest pixel in the bottom row.

03

Remove and repeat

The seam is cut out, the energy is computed again and the next seam is found, until the picture is the target size. Horizontal seams are found the same way on the transposed picture.

The page runs the team’s C++ code compiled to WebAssembly. Pictures stay in your browser
