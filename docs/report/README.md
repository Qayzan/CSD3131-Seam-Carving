# Report (assembled by RB)

Drafts, figures and the final PDF go here. Every owner writes the report text for their own items (see [../team.md](../team.md)). RB assembles it and adds the links, team IDs, AI Usage Declaration and formatting.

Required contents (brief item 9a): team id + members with SIT IDs; answers to Item 2; algorithm, design, implementation, results/evaluation, comparison and discussion; GitHub and video links; AI usage declaration (from [../ai_usage_log.md](../ai_usage_log.md)). See [../requirements.md](../requirements.md) for the full checklist.

Word lock files (`~$*`) are git-ignored. Commit exported PDFs and figures, not temporary files.
